语音通话 Beta 全局·所有会话可用
默认关闭。打开后，会话页面顶栏才会出现话筒图标；关掉只是收起入口，下面的语音设置全部保留，随时可配。
通话用三路模型：听（语音识别）、想（对话大脑）、说（语音合成）。识别与合成走下面独立的「语音接口」，和「接口管理」里的聊天渠道完全无关 —— 聊天渠道是给文本模型用的，拿它发语音会报 401。大脑直接跟随当前会话。
语音接口（识别 + 合成） 语音要有自己的地址和密钥。填一次就行，识别和合成共用。可以加多个，随时切换。
听 · 语音识别（ASR） 只接受 wav / mp3。客户端会先做端点检测，静音片段不会送进识别（上游会把静音幻觉成文字）。
想 · 对话大脑 通话的大脑直接使用当前会话选择的模型，不单独设置。想换就换会话的模型。
说 · 语音合成（TTS） 9 个内置音色。想要独占音色可用「声音设计」（描述一个声音）或「声音克隆」（上传参考音频）。
参考音建议 5~20 秒清晰单人语音。留空则用上面的音色。
对话手感 AI 说话时你一开口，它立刻停下来听你说。关掉则必须等它说完。 调高更容易被识别为「在说话」，嘈杂环境建议调低。 默认关闭 —— 挂着聊天就该一直挂着。打开后默认 1 小时没人说话才挂断，可以改。 把「语速偏快 · 音量偏低」这类声音状态显示出来，同时也会喂给大脑。 跟随会话＝用这个会话自己的「深度思考」开关。开着更慢（实测首字约 +0.9 秒）但想得更细，思考过程会显示在通话界面里；关掉最快。
时间与语速 默认关闭。打开后模型会知道现在几点、这通电话打了多久、上一句隔了多久 —— 长时间挂着聊天时，不会把「隔了两小时」当成「紧接着」。 正常语速 保持音高 = 快慢变了，但声音不变尖、不变粗。跟着变调 = 传统加速，声音会变尖，更省电，但不像真人。
音频路由 自动 = 插耳机走耳机、拔掉走外放；钉死某一项适合外放回声大、或耳机一直没被识别出来时。实际路由读的是原生回报，浏览器里没有这一层。
依次检查：识别渠道可达 → 合成渠道可达（各发一次极短请求）。不消耗对话额度。
联网搜索 全局配置·按会话开关
把 DeepSeek 官方的「网页搜索 / 网页抓取」接口（/v1/tools/search、/v1/tools/fetch）包装成两个工具交给模型：web_search 与 fetch_url。要不要联网、搜什么词、搜几条、要不要连正文、要不要再抓某页全文，全由模型自己决定 —— 不需要联网的问题它会直接回答，不会白发一次检索。
按成功请求计费：5 元 / 千次（Search、Fetch 各算各的，失败与空结果不计费）。这里是全局配置；开关在「本次对话 → 联网搜索」（按会话生效）。 自动只挑 DeepSeek 官方接口（第三方中转站通常没有 tools 接口）。想用别家网关请在右侧下拉里显式选中。
必须是 DeepSeek 兼容的 /v1/tools/search 与 /v1/tools/fetch。
没有「条数 / 要不要正文」这类旋钮了 —— 它们是 web_search 自己的参数（count、need_content），由模型按问题决定。全局设一个默认值，等于又留了个"替它决定"的后门。 在回复下方列出本次引用的网页（标题 + 站点 + 日期），点标题用系统浏览器打开。 只影响此后新建的会话；已有会话保持各自原来的开关状态。
数据管理 全量导出/导入
导出当前所有对话、接口配置、设置和图库原图（打包成一个 .zip，导出后走系统分享，存哪由你决定）；导入支持新的 .zip 备份，也兼容以前导出的 .json。
覆盖：直接替换当前所有数据。合并：相同 ID 的对话/接口以导入数据为准。
